TNov · бета-тест

Revit × Claude, Codex и Qwen

Коннектор из плагина TNov даёт нейросети доступ к модели, открытой у вас в Revit. Можно спросить о модели словами, найти и выделить элементы, посмотреть вид, а с ростом уровня доступа — поправить параметры или запустить скрипт. Работает с Claude (Anthropic), Codex (OpenAI) и Qwen (Alibaba).

Как это устроено

Кнопка Нейросетошная в Revit включает у вас на компьютере небольшой сервер. Claude Code, Codex или Qwen Code подключается к нему и получает набор инструментов: «найти элементы», «прочитать параметры», «показать вид» и другие. Вы пишете задачу обычным текстом, нейросеть сама решает, какие инструменты вызвать, и отвечает.

Инструменты, уровень доступа и защита модели у всех нейросетей одинаковые. Можно пользоваться любой из них или несколькими. Revit и модель остаются у вас. Нейросеть видит только то, что прочитала через инструменты, и только пока Revit открыт, а коннектор включён.

Часть 1 · Настройка, один раз

Что понадобится

  • Revit с плагином TNov последней версии. На вкладке TNov, панель Настройки, должна быть кнопка Нейросетошная с фиолетовым значком-схемой.
  • Одна из нейросетей на ваш аккаунт. Запросы к Revit расходуют лимиты вашей подписки, как обычная переписка.
Claude

Подписка Claude Pro, Max или Team и приложение Claude для Windows (claude.ai/download). Права администратора не нужны.

Основной способ — вкладка Code в приложении (Claude Code). Обычный чат подключается через мост. На сайте claude.ai коннектор не работает.

Codex

Платный тариф ChatGPT с доступом к Codex и Codex на компьютере. Проще всего — приложение ChatGPT для Windows, Codex встроен в него: скачайте с chatgpt.com/ru-RU/download и откройте в приложении раздел Codex. Подойдут и Codex для терминала или расширение для VS Code (developers.openai.com/codex).

Все варианты Codex берут настройки из одного файла, поэтому подключение делается один раз. На сайте chatgpt.com коннектор не работает.

Qwen

Qwen Code — консольная программа Alibaba. Установка и вход — по инструкции на qwenlm.github.io/qwen-code-docs. Вход — по ключу Alibaba Cloud (подписка Coding Plan, платно). Бесплатный вход через аккаунт qwen.ai закрыт 15 апреля 2026 года, инструкции в интернете с ним устарели.

Данные модели, которые прочитает Qwen, уходят на серверы Alibaba Cloud. На сайте chat.qwen.ai коннектор не работает.

Подключение к Claude Code

  1. Подключите из Revit

    Нажмите кнопку Нейросетошная, в разделе Claude нажмите Подключить к Claude Code. Плагин сам создаст рабочую папку %USERPROFILE%\Claude\Revit с настройками и пропишет коннектор в настройки Claude Code. Права администратора не нужны.

    Коннектор подключается через мост: после перезапуска Revit или остановки коннектора связь восстанавливается сама, новый чат начинать не нужно. Если вы раньше подключались файлом .mcp.json или командой с адресом http://localhost:48884/mcp, просто нажмите кнопку — она заменит старую запись.

    Вручную (для Claude Code в терминале): скопируйте команду из раздела Claude окна «Нейросетошная» и выполните её в PowerShell, не в чате Claude. Перед этим один раз нажмите кнопку — она кладёт на диск файл моста.

  2. Откройте папку в Claude Code

    Приложение Claude → вкладка Code → новый сеанс → выберите папку %USERPROFILE%\Claude\Revit (обычно C:\Users\ваш_логин\Claude\Revit).

    При первом открытии Claude Code спросит, доверять ли серверу revit. Разрешите — это и есть коннектор TNov.

  3. Проверьте связь

    Откройте модель в Revit, нажмите кнопку Нейросетошная, затем напишите в Claude Code:

    Какая модель сейчас открыта в Revit? Сколько в ней уровней?

    Claude должен назвать файл модели и уровни. Если Revit был закрыт, Claude сообщит, что Revit не отвечает, — запустите коннектор и повторите. Если он отвечает, что не видит Revit вообще, загляните в раздел «Если не работает».

Обычный чат Claude Desktop

Если Claude Code недоступен (например, на бесплатном тарифе), коннектор можно подключить к обычному чату приложения Claude через мост.

  1. Подключите мост из Revit

    Нажмите кнопку Нейросетошная, в разделе Claude нажмите Claude Desktop. Плагин сам пропишет мост в настройки приложения Claude.

  2. Перезапустите Claude Desktop

    Закройте приложение полностью: значок в трее → Выход. Откройте снова и начните новый чат. Инструменты Revit появятся в меню инструментов чата.

Лимиты бесплатного тарифа небольшие, а работа с моделью тратит их быстро, особенно изображения видов. Для регулярной работы нужен Claude Code.

Подключение к Codex

Ставьте ChatGPT и Codex только со страницы OpenAI. В Microsoft Store есть сторонние приложения с названиями вроде «Codex AI for (OpenAI ChatGPT)». Это обычные чат-боты от других издателей, к Revit они не подключаются. У настоящего приложения издатель — OpenAI.

  1. Подключите коннектор из Revit

    Нажмите кнопку Нейросетошная, в разделе Codex нажмите Подключить к Codex. Плагин сам пропишет сервер revit в файл настроек Codex %USERPROFILE%\.codex\config.toml. Остальные ваши настройки не меняются, копия файла сохраняется рядом как config.toml.bak-tnov.

    Права администратора не нужны: файл лежит в вашем профиле. Если кнопка не сработала, можно вручную: Скопировать блок в разделе Codex, открыть %USERPROFILE%\.codex\config.toml в Блокноте, вставить блок в конец файла и сохранить.

    Блок и команды из окна не отправляйте в чат Codex или Claude. Нейросеть их не выполнит, а только начнёт рассуждать о них. Подключение делается кнопкой в Revit или правкой файла.

  2. Перезапустите Codex

    Полностью закройте приложение ChatGPT (или Codex) и откройте снова, затем начните новый сеанс в разделе Codex. Сервер revit должен появиться в списке MCP-серверов в настройках Codex (в терминале: команда codex mcp list).

  3. Проверьте связь

    Откройте модель в Revit (окно «Нейросетошная» уже включило коннектор) и напишите в Codex:

    Какая модель сейчас открыта в Revit? Сколько в ней уровней?

    Если Revit закрыт, Codex всё равно запустится и сообщит, что Revit не отвечает. Это нормально.

Подключение к Qwen Code

  1. Подключите коннектор из Revit

    Нажмите кнопку Нейросетошная, в разделе Qwen нажмите Подключить к Qwen Code. Плагин сам пропишет сервер revit в файл настроек %USERPROFILE%\.qwen\settings.json. Остальные ваши настройки не меняются, копия файла сохраняется рядом как settings.json.bak-tnov.

    Права администратора не нужны. Вручную: Скопировать фрагмент в разделе Qwen и добавить сервер revit из него в раздел mcpServers того же файла. Фрагмент не отправляйте в чат Qwen.

  2. Перезапустите Qwen Code

    Закройте Qwen Code и запустите снова. Команда /mcp внутри Qwen Code показывает подключённые серверы, среди них должен быть revit.

  3. Проверьте связь

    Откройте модель в Revit (окно «Нейросетошная» уже включило коннектор) и напишите в Qwen Code:

    Какая модель сейчас открыта в Revit? Сколько в ней уровней?

    Если Revit закрыт, Qwen Code всё равно запустится и сообщит, что Revit не отвечает. Это нормально.

Часть 2 · Как работать каждый день

Порядок работы

  1. Revit: откройте модель и нажмите «Нейросетошная»

    Коннектор включается вручную при каждом запуске Revit. В окне видно состояние каждой нейросети, их адреса и ваш уровень доступа. Окно можно просто закрыть.

  2. Новый сеанс в Claude Code, Codex или Qwen Code

    Если коннектор включили уже после открытия сеанса, начните новый сеанс, чтобы нейросеть подхватила инструменты.

  3. Пишите задачу обычным языком

    Называйте категории и параметры так же, как в интерфейсе Revit: «Стены», «Комментарии», «Марка». Значения указывайте в единицах проекта, как в свойствах: «3000», «Да».

  4. Проверяйте результат в Revit

    Попросите выделить найденные элементы, и они подсветятся в Revit. Перед правками сначала посмотрите список.

Примеры запросов

уровень 1 · чтение

Сколько дверей на каждом уровне и каких типов? Сведи в таблицу.

уровень 1 · чтение

Найди помещения без номера и выдели их в Revit.

уровень 1 · оформление

Промаркируй все окна на активном виде, у которых нет марки.

уровень 1 · листы

Раздели спецификацию «Ведомость перемычек» на части по 30 строк и размести их на листах серии КЖ.

уровень 1 · подсчёт

Посчитай массу арматуры по каждой марке конструкции.

уровень 2 · 3D-элементы

Всем стенам толщиной больше 400 мм на «Этаж 3» поставь «Комментарии» = «Проверить». Сначала покажи список.

уровень 3 · удаление

Удали все пустые помещения на этаже 2. Сначала покажи список.

В хорошем запросе сказано, что найти, где и в каком виде нужен ответ. Если нейросеть поняла неверно, уточните следующим сообщением: переписка продолжается.

Скиллы — общие рецепты

Скилл — проверенное решение типовой задачи (например, «разбить спецификацию по листам»), которое коллега сохранил в общую библиотеку. Нейросеть сама ищет подходящий скилл перед тем, как писать новый скрипт, и запускает его с вашими параметрами. Скиллы доступны только в корпоративной конфигурации.

  • Как сохранить. Когда задача решена и результат устраивает, напишите: «сохрани это как скилл „…“». Revit покажет окно с названием, описанием, параметрами и кодом. Там же напишите короткую инструкцию для коллег и прикрепите файлы (шаблон, пример, схему), затем нажмите «Опубликовать». Автор указывается автоматически. Сохранить можно только код, который уже отработал у вас в Revit без ошибок — в этом или прошлых сеансах.
  • Правка. Инструкцию и файлы скилла меняют его автор и сотрудники отдела BIM: на вкладке «Скиллы» окна «Нейросетошная» можно изменить текст, заменить или удалить файл, прикрепить ещё один.
  • Кто публикует. Уровень 2–3 — сразу для всех. Уровень 1 — черновиком: его видят коллеги с уровнем 2–3 и могут опубликовать.
  • Как найти. Просто опишите задачу — нейросеть сама проверит библиотеку. Список скиллов, описания и код — на вкладке Скиллы окна «Нейросетошная».
  • Безопасность. Скилл выполняется с вашими правами в текущей модели, с той же проверкой изменений и подтверждением в Revit, где видны название, автор и версия скилла.
  • С любой нейросетью. Скилл, сохранённый через Claude, работает и в Codex, и в Qwen: код выполняет плагин, нейросеть только подставляет параметры.

Разрешения

Перед вызовом инструмента Revit Claude Code, Codex и Qwen Code могут спросить разрешения. В запросе видно название инструмента, например revit · find_elements, и его параметры. Как часто спрашивать, зависит от настроек программы.

  • Чтение (get_document_info, find_elements, summarize_elements, list_views, export_view_image, wiki_search и т. п.) ничего не меняет в модели. Его можно разрешить всегда.
  • Изменения 3D (set_parameters, place_family_instance, move_elements, delete_elements): разрешайте каждый раз отдельно и читайте, что именно будет сделано.
  • Скрипты (execute_csharp): Revit дополнительно сам покажет код, права скрипта в этой модели и спросит подтверждение. В заголовке окна видно, кто прислал код: Claude, Codex или Qwen. Если не понимаете, что делает код, нажмите «Отмена» и попросите объяснить.

Правила безопасной работы

На время бета-теста работайте на копиях или отсоединённых моделях. С локальными копиями рабочих файлов из хранилища — только уровень 1.

  • Нейросеть работает с активным документом. Перед запросом переключитесь на нужную модель.
  • Каждое изменение записывается отдельной операцией в списке отмены с подписью «Claude:», «Codex:» или «Qwen:». Отменяется Ctrl+Z в Revit.
  • Пока в Revit открыт диалог или идёт команда (синхронизация, печать), запрос ждёт и через 2 минуты получает отказ. Закройте окно и попросите повторить.
  • Нейросеть может ошибиться в выборе элементов. Для массовых правок сначала просите список и выделение.
  • Не давайте разным нейросетям одновременно менять одну модель: их правки могут пересечься.
  • Изображения видов расходуют лимиты подписки заметно быстрее текста.
Часть 3 · Справка

Уровни доступа

Возможности открываются постепенно. Инструменты выше вашего уровня нейросеть не видит и вызвать не может. Уровень общий для всех нейросетей.

Ур.Что может нейросеть
1 Читать модель целиком, считать объёмы и арматуру по всей модели, проверять высоты, расстояния и пересечения. Оформлять: марки и другие аннотации, виды, листы, размещение видов и спецификаций на листах, импорт изображений. Экспортировать в IFC, NWC, DWG, PDF, FBX. 3D-элементы не меняет и ничего не удаляет.
2 Плюс 3D-элементы: заполнять параметры, размещать и перемещать элементы, до 50 штук за запрос.
3 Всё, включая параметры типов, удаление элементов и скрипты без ограничений.

Нестандартные задачи нейросеть решает небольшими C#-скриптами. Плагин проверяет, что изменил скрипт, и отменяет его целиком, если тот вышел за права вашего уровня в этой модели. Например, на уровне 1 скрипт может расставить марки, а попытку сдвинуть стену плагин отменит.

Где какой уровень действует

Ограничения зависят от модели. Локальная копия файла-хранилища — модель, открытая из хранилища без отсоединения. Свободная модель — отсоединённая от хранилища или обычный файл без совместной работы.

Ур.Где действует
1Любые модели
2Любые модели. Скрипты меняют 3D-элементы только в свободных моделях
3Любые модели

Вне разрешённых моделей нейросеть работает на правах уровня 1 и сама скажет об этом.

Как получить уровень

Уровень 2 открывается сам, как только выполнится любое из условий: больше 3 дней работы с коннектором подряд, больше 5 дней всего или больше 30 успешных операций. Запросы всех нейросетей считаются вместе. Уровень 3 и другие изменения назначает BIM-менеджер.

В пределах доступного уровня можно временно выбрать более низкий (например, для тестов) в окне кнопки «Нейросетошная». Когда вам откроют новый уровень, выбор сам поднимется до него.

Текущий уровень, прогресс и уровень в последней модели видны в окне кнопки Нейросетошная. После смены уровня начните новый сеанс в Claude Code, Codex или Qwen Code, чтобы появились новые инструменты.

База знаний

Нейросеть сама заглядывает в базу знаний tnov.pm-nova.ru/wiki, когда вопрос касается стандартов Новации, правил оформления или функций TNov, и даёт ссылку на статью. Можно попросить явно: «Посмотри в базе знаний, как у нас оформляют узлы».

Мониторинг подключения

Состояние видно в окне кнопки Нейросетошная: у каждой нейросети свой раздел, в его заголовке — строка состояния, она обновляется каждые 2 секунды. Раздел раскрывается щелчком: внутри адрес и подключение. Какие разделы раскрыты, окно запоминает.

Подключён: запросы были за последние 10 минут.
Ещё не подключался или нет запросов: коннектор работает, но эта нейросеть давно не обращалась.
Коннектор остановлен: нажмите «Запустить» или кнопку «Нейросетошная» на ленте.

Кнопка Проверить показывает, отвечают ли адреса нейросетей и прописан ли коннектор в Claude Code, Claude Desktop, Codex и Qwen Code. В окне кнопки видно число запросов и последнюю ошибку для каждой нейросети.

Проверка «прописан ли в Claude Code» находит только подключение командой из терминала. Если вы подключались через файл .mcp.json, строка «не прописан» — это нормально.

Если не работает

Нейросеть говорит, что у неё нет доступа к Revit
Проверьте по порядку: Revit открыт и коннектор запущен (окно «Нейросетошная»); в окне нажата кнопка подключения вашей нейросети («Подключить к Claude Code», «…к Codex», «…к Qwen Code»), и программа перезапущена после этого. Для Claude Code — сеанс открыт в папке %USERPROFILE%\Claude\Revit; если Claude Code спрашивал про сервер revit, а вы отклонили, откройте новый сеанс и разрешите. Если вы подключались раньше напрямую по адресу, «Проверить» подскажет нажать «Подключить к Claude Code»: со старым подключением после перезапуска Revit инструменты пропадают до нового чата.
Codex отвечает, что не может подключиться к Revit или к вашему окружению
Нажмите «Проверить» в окне «Нейросетошная». Если там «Codex ни разу не запускал мост», это не тот Codex: сайт chatgpt.com или стороннее приложение из Microsoft Store. Узнать, что установлено, можно в PowerShell командой Get-StartApps | Where-Object Name -match 'codex|chatgpt': стороннее приложение будет с чужим издателем в AppID (например, ChatDog…). Удалите его и поставьте ChatGPT с chatgpt.com/ru-RU/download.
Codex в ответ на команду рассуждает о ней, вместо того чтобы подключиться
Команду или блок отправили в чат Codex. Нейросеть их не выполняет. Нажмите «Подключить к Codex» в окне «Нейросетошная» и перезапустите Codex.
Подключали Codex командой codex mcp add
Так тоже работает, но остаются стандартные таймауты Codex, и долгие скрипты могут обрываться. Нажмите «Подключить к Codex»: кнопка заменит эту запись своей, с увеличенными таймаутами.
«В config.toml уже есть сервер revit, прописанный не TNov»
В настройках Codex уже есть сервер с именем revit, который ведёт не к TNov, например от другой надстройки. Плагин его не трогает. Удалите или переименуйте этот блок в %USERPROFILE%\.codex\config.toml и нажмите кнопку снова.
«Revit не ответил за 120 с»
В Revit открыт диалог, идёт синхронизация или другая команда. Освободите Revit и попросите повторить.
Нейросеть говорит, что такого инструмента нет
Инструмент выше вашего уровня доступа. Уровень видно в окне кнопки «Нейросетошная».
«Изменения отменены»
Скрипт вышел за права вашего уровня в этой модели, например попытался изменить 3D-элементы на уровне 1 или в локальной копии хранилища. Плагин отменил всё, что сделал скрипт. Нейросеть обычно сама предлагает другой путь; если нужен более высокий уровень, работайте в отсоединённой модели или обратитесь к BIM-менеджеру.
В Revit загружен другой MCP-коннектор
Окно «Нейросетошная» показывает красное предупреждение, если в Revit стоит сторонняя надстройка-коннектор. Её действия не ограничены уровнями TNov и не попадают в журнал. Отключите её в настройках Claude Code, Codex или Qwen Code или удалите надстройку.
Открыто два Revit
Второй Revit получает порт 48885, он указан в окне «Нейросетошная». Claude работает с тем Revit, чей адрес записан в .mcp.json; для второго заведите отдельную папку со своим файлом. Codex и Qwen Code работают с тем Revit, из которого последний раз нажимали кнопку подключения.
«Не удалось открыть порты»
Порты 48884–48893 заняты другими программами. Сообщите BIM-менеджеру.
Скрипт не компилируется в Revit 2022
В Revit 2022 скрипты собираются старым компилятором C# 5. Попросите переписать код без новых конструкций языка.

Что сообщать

По каждой находке отправьте BIM-менеджеру TNov:

  • версию Revit и плагина (окно «Настройки»);
  • какой нейросетью пользовались: Claude, Codex или Qwen;
  • ваш запрос дословно;
  • что ожидали и что получилось, со скриншотом;
  • скриншот окна «Нейросетошная» после нажатия «Проверить».
TNov · коннектор Revit — Claude, Codex и Qwen (MCP), бета-версия. Коннектор принимает запросы только с вашего компьютера. Данные модели, которые прочитала нейросеть, уходят в Anthropic (Claude), OpenAI (Codex) или Alibaba Cloud (Qwen) в составе вашего сеанса, как и всё, что вы пишете. Вызовы инструментов и тексты скриптов записываются в журнал TNov.
