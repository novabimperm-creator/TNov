Как это устроено

Кнопка Нейросетошная в Revit включает у вас на компьютере небольшой сервер. Qwen Code подключается к нему и получает набор инструментов: «найти элементы», «прочитать параметры», «показать вид» и другие. Вы пишете задачу обычным текстом, Qwen сам решает, какие инструменты вызвать, и отвечает.

Revit и модель остаются у вас. Qwen видит только то, что прочитал через инструменты, и только пока Revit открыт, а коннектор включён. Данные, которые он прочитал, уходят на серверы Alibaba Cloud вместе с вашими сообщениями.

Что понадобится

  • Revit с плагином TNov последней версии. На вкладке TNov, панель Настройки, должна быть кнопка Нейросетошная.
  • Аккаунт Alibaba Cloud с подпиской Coding Plan. Подписка платная. Оплату и тариф согласуйте с руководителем или BIM-менеджером до оформления.
  • Qwen Code на компьютере. Права администратора для установки не нужны.

Бесплатного входа через аккаунт qwen.ai больше нет. Alibaba закрыла его 15 апреля 2026 года. В интернете много старых инструкций со входом «Qwen OAuth» и бесплатными лимитами — они больше не работают.

Настройка, один раз

1. Установите Qwen Code

  1. Откройте PowerShell

    Меню «Пуск» → наберите PowerShell → откройте Windows PowerShell. Запускать от имени администратора не нужно.

  2. Выполните команду установки

    Вставьте команду из официальной инструкции Qwen Code и нажмите Enter. Она скачивает Qwen Code вместе со всем нужным для работы, отдельно ставить Node.js не надо.

    irm https://qwen-code-assets.oss-cn-hangzhou.aliyuncs.com/installation/install-qwen-standalone.ps1 | iex

    Официальная инструкция по установке: qwenlm.github.io/qwen-code-docs. Если политика ИБ требует проверять скрипты, сначала откройте ссылку из команды в браузере, сохраните файл и покажите его администратору.

  3. Перезапустите PowerShell и проверьте

    Закройте окно PowerShell, откройте новое и выполните:

    qwen --version

    Должен появиться номер версии. Если установка выдала «Could not resolve host» или PowerShell пишет, что команда не найдена, загляните в раздел «Если не работает».

2. Аккаунт Alibaba Cloud и ключ Coding Plan

  1. Войдите в Alibaba Cloud через Google

    Откройте alibabacloud.com → Log In. На странице входа выберите вход через Google и укажите свой Google-аккаунт. При первом входе Alibaba Cloud создаст аккаунт и попросит заполнить профиль.

    Если кнопки Google на странице нет, зарегистрируйтесь по адресу электронной почты — дальше всё так же.

  2. Оформите подписку Coding Plan

    Откройте консоль Model Studio, раздел Coding Plan, и оформите подписку на согласованный тариф. Работайте в международной консоли (International), а не в китайской.

  3. Скопируйте ключ

    На странице Coding Plan скопируйте ключ. Он начинается с sk-sp-. Обычный ключ Model Studio вида sk-… для Coding Plan не подходит.

    Ключ — как пароль. Не пересылайте его в мессенджерах, не вставляйте в чат Qwen и не публикуйте. По условиям Alibaba ключ Coding Plan можно использовать только в программах для работы с кодом вроде Qwen Code, а не в своих скриптах.

3. Войдите в Qwen Code

  1. Запустите Qwen Code

    В PowerShell выполните команду qwen.

  2. Выберите вход по Coding Plan

    Если Qwen Code не предложил вход сам, наберите /auth и нажмите Enter. Дальше выберите:

    Alibaba ModelStudioCoding PlanInternational

    и вставьте ключ sk-sp-….

    Ключ сохранится в настройках Qwen Code в вашем профиле, вводить его каждый раз не нужно. Названия пунктов меню могут немного отличаться в разных версиях.

  3. Проверьте

    Напишите Qwen любой вопрос, например «привет». Если он ответил, вход выполнен.

4. Подключите Qwen Code к Revit

  1. Нажмите кнопку в Revit

    Откройте модель, нажмите Нейросетошная на вкладке TNov, в разделе Qwen нажмите Подключить к Qwen Code. Плагин сам пропишет сервер revit в файл %USERPROFILE%\.qwen\settings.json. Остальные настройки Qwen Code не меняются, копия файла сохраняется рядом как settings.json.bak-tnov.

  2. Перезапустите Qwen Code

    Закройте Qwen Code (команда /quit или закрыть окно PowerShell) и снова запустите qwen. Наберите /mcp: в списке должен быть сервер revit.

  3. Проверьте связь с моделью

    Напишите в Qwen Code:

    Какая модель сейчас открыта в Revit? Сколько в ней уровней?

    Qwen должен назвать файл модели и уровни. Если Revit закрыт или кнопка не нажата, Qwen сообщит, что Revit не отвечает.

Как работать каждый день

Порядок работы

  1. Revit: откройте модель и нажмите «Нейросетошная»

    Коннектор включается вручную при каждом запуске Revit. Окно можно просто закрыть.

  2. PowerShell: запустите qwen

    Если коннектор включили уже после запуска Qwen Code, перезапустите Qwen Code.

  3. Пишите задачу обычным языком

    Называйте категории и параметры, как в интерфейсе Revit: «Стены», «Комментарии», «Марка». Значения — в единицах проекта: «3000», «Да».

  4. Проверяйте результат в Revit

    Попросите Qwen выделить найденные элементы — они подсветятся в Revit. Перед правками сначала посмотрите список.

Примеры запросов

уровень 1 · чтение

Сколько дверей на каждом уровне и каких типов? Сведи в таблицу.

уровень 1 · оформление

Промаркируй все окна на активном виде, у которых нет марки.

уровень 1 · подсчёт

Посчитай массу арматуры по каждой марке конструкции.

уровень 2 · 3D-элементы

Всем стенам толщиной больше 400 мм на «Этаж 3» поставь «Комментарии» = «Проверить». Сначала покажи список.

Подтверждения и безопасность

  • Перед вызовом инструмента Revit Qwen Code может спросить разрешения. Чтение модели можно разрешать всегда, изменения — читайте, что именно будет сделано.
  • Перед запуском скрипта Revit сам покажет код и права скрипта в этой модели. В заголовке окна видно, что код прислал Qwen. Если не понимаете, что делает код, нажмите «Отмена» и попросите объяснить.
  • Qwen работает с активным документом. Перед запросом переключитесь на нужную модель.
  • Каждое изменение записывается в списке отмены с подписью «Qwen:» и отменяется Ctrl+Z в Revit.
  • Пока в Revit открыт диалог или идёт синхронизация, Qwen ждёт и через 2 минуты получает отказ. Закройте окно и попросите повторить.
  • Не давайте нескольким нейросетям одновременно менять одну модель.
  • Вызовы инструментов и тексты скриптов записываются в журнал TNov.

На время бета-теста работайте на копиях или отсоединённых моделях.

Уровни доступа

Уровень общий для всех нейросетей. Инструменты выше вашего уровня Qwen не видит и вызвать не может.

Ур.Что может Qwen
1Читать модель целиком, считать объёмы и арматуру, проверять высоты и пересечения. Оформлять: марки, виды, листы, спецификации на листах, изображения. Экспортировать. 3D-элементы не меняет и ничего не удаляет.
2Плюс 3D-элементы: заполнять параметры, размещать и перемещать, до 50 штук за запрос. В локальной копии файла-хранилища скрипты 3D-элементы не меняют.
3Всё, включая параметры типов, удаление элементов и скрипты без ограничений.

Уровень 2 открывается сам, как только выполнится любое из условий: больше 3 дней работы с коннектором подряд, больше 5 дней всего или больше 30 успешных операций. Уровень 3 назначает BIM-менеджер. Текущий уровень виден в окне кнопки Нейросетошная, там же можно временно выбрать уровень ниже. После смены уровня перезапустите Qwen Code.

Если не работает

Установка: «Could not resolve host» или «curl.exe download failed»

Компьютер выходит в интернет через прокси, а установщик (и потом сам Qwen Code) системный прокси Windows не видит. Выполните в том же окне PowerShell команду ниже: она берёт адрес прокси из настроек Windows и передаёт его установщику. Затем повторите установку.

$s = Get-ItemProperty 'HKCU:\Software\Microsoft\Windows\CurrentVersion\Internet Settings'; $p = $s.ProxyServer; if ($s.ProxyEnable -and $p) { $h = $p -split ';' | Where-Object { $_ -like 'https=*' } | Select-Object -First 1; if (-not $h) { $h = ($p -split ';')[0] }; $h = 'http://' + ($h -replace '^\w+=', ''); $env:HTTPS_PROXY = $h; $env:HTTP_PROXY = $h; $env:NO_PROXY = 'localhost,127.0.0.1,::1'; "Прокси: $h" } else { 'В Windows прокси не задан — обратитесь к администратору' }

Эти настройки действуют только в текущем окне, а прокси нужен и для работы Qwen Code. Чтобы не задавать его каждый раз, сохраните его для своей учётной записи (права администратора не нужны). Сразу после команды выше выполните:

setx HTTPS_PROXY $env:HTTPS_PROXY; setx HTTP_PROXY $env:HTTP_PROXY; setx NO_PROXY "localhost,127.0.0.1,::1"

и откройте новое окно PowerShell. NO_PROXY с localhost обязателен: без него запросы к коннектору Revit уйдут в прокси. Если вторая команда ответила, что прокси в Windows не задан, или прокси настроен через автоматический сценарий (PAC), адрес прокси подскажет администратор.

Qwen Code не отвечает или пишет об ошибке соединения с Alibaba
Та же причина, что и выше: Qwen Code не видит прокси. Задайте переменные из предыдущего пункта (лучше через setx) и перезапустите PowerShell и Qwen Code.
PowerShell: «qwen» не является именем командлета
Закройте и снова откройте PowerShell после установки. Если не помогло, выполните where.exe qwen и пришлите результат BIM-менеджеру.
Ошибка про Qwen OAuth или «discontinued»
Qwen Code пытается войти старым бесплатным способом. Наберите /auth и выберите Alibaba ModelStudio → Coding Plan.
Ошибка 401 после ввода ключа
Чаще всего выбран не тот регион или не тот ключ. Нужен ключ sk-sp-… со страницы Coding Plan и регион International. Повторите /auth.
В /mcp нет сервера revit
Нажмите «Подключить к Qwen Code» в окне «Нейросетошная» и перезапустите Qwen Code.
Qwen говорит, что Revit не отвечает
Revit закрыт, кнопка «Нейросетошная» не нажата или в Revit открыт диалог. Освободите Revit и попросите повторить.
Qwen говорит, что такого инструмента нет
Инструмент выше вашего уровня доступа. Уровень видно в окне кнопки «Нейросетошная».
«Изменения отменены»
Скрипт вышел за права вашего уровня в этой модели, и плагин отменил всё, что он сделал. Qwen обычно сам предлагает другой путь.

Что сообщать

По каждой находке отправьте BIM-менеджеру TNov:

  • версию Revit и плагина (окно «Настройки»);
  • что пользовались Qwen Code, и ваш запрос дословно;
  • что ожидали и что получилось, со скриншотом;
  • скриншот окна «Нейросетошная» после нажатия «Проверить».
TNov · коннектор Revit — Qwen (MCP), бета-версия, корпоративная конфигурация. Коннектор принимает запросы только с вашего компьютера. Данные модели, которые прочитал Qwen, уходят в Alibaba Cloud в составе вашего сеанса, как и всё, что вы пишете. Вызовы инструментов и тексты скриптов записываются в журнал TNov.
