Revit × Claude

Коннектор из плагина TNov даёт Claude доступ к модели, открытой у вас в Revit. Можно спросить о модели словами, найти и выделить элементы, посмотреть вид, а с ростом уровня доступа — поправить параметры или запустить скрипт.

Как это устроено

Кнопка Claude в Revit включает у вас на компьютере небольшой сервер. Claude Code подключается к нему и получает набор инструментов: «найти элементы», «прочитать параметры», «показать вид» и другие. Вы пишете задачу обычным текстом, Claude сам решает, какие инструменты вызвать, и отвечает.

Revit и модель остаются у вас. Claude видит только то, что прочитал через инструменты, и только пока Revit открыт, а коннектор включён.

Часть 1 · Настройка, один раз

Что понадобится

  • Revit с плагином TNov последней версии. На вкладке TNov, панель Настройки, должна быть кнопка Claude с оранжевым значком.
  • Подписка Claude: Pro, Max или Team, на ваш аккаунт. Запросы к Revit расходуют лимиты вашей подписки, как обычная переписка.
  • Приложение Claude для Windows (claude.ai/download). Права администратора для установки не нужны. Войдите под своим аккаунтом.

Нужна именно вкладка Code в приложении Claude (Claude Code). В обычном чате (вкладка Chat) и на сайте claude.ai коннектор не работает.

Подключение к Claude Code

  1. Создайте рабочую папку

    Например, C:\Claude\Revit. В ней лежит настройка, по которой Claude Code находит Revit, поэтому работать с Revit через Claude нужно из этой папки.

  2. Положите в неё файл настроек

    Откройте Блокнот, вставьте текст ниже и сохраните в эту папку под именем .mcp.json. В окне сохранения выберите тип файла Все файлы (*.*), иначе Блокнот допишет .txt.

    {
  "mcpServers": {
    "revit": {
      "type": "http",
      "url": "http://localhost:48884/mcp"
    }
  }
}

    Если вы пользуетесь Claude Code в терминале, вместо файла можно выполнить одну команду. Она подключает Revit сразу во всех папках. Её же копирует кнопка в окне коннектора в Revit.

    claude mcp add --transport http --scope user revit http://localhost:48884/mcp

  3. Откройте папку в Claude Code

    Приложение Claude → вкладка Code → новый сеанс → выберите папку C:\Claude\Revit.

    При первом открытии Claude Code спросит, доверять ли серверу revit из файла .mcp.json. Разрешите — это и есть коннектор TNov.

  4. Проверьте связь

    Откройте модель в Revit, нажмите кнопку Claude, затем напишите в Claude Code:

    Какая модель сейчас открыта в Revit? Сколько в ней уровней?

    Claude должен назвать файл модели и уровни. Если он отвечает, что не видит Revit, загляните в раздел «Если не работает».

Часть 2 · Как работать каждый день

Порядок работы

  1. Revit: откройте модель и нажмите «Claude»

    Коннектор включается вручную при каждом запуске Revit. В окне видно адрес и ваш уровень доступа; окно можно просто закрыть.

  2. Claude Code: новый сеанс в рабочей папке

    Если коннектор включили уже после открытия сеанса, начните новый сеанс, чтобы Claude подхватил инструменты.

  3. Пишите задачу обычным языком

    Называйте категории и параметры так же, как в интерфейсе Revit: «Стены», «Комментарии», «Марка». Значения указывайте в единицах проекта, как в свойствах: «3000», «Да».

  4. Проверяйте результат в Revit

    Попросите Claude выделить найденные элементы, и они подсветятся в Revit. Перед правками сначала посмотрите список.

Примеры запросов

уровень 1 · чтение

Сколько дверей на каждом уровне и каких типов? Сведи в таблицу.

уровень 1 · чтение

Найди помещения без номера и выдели их в Revit.

уровень 1 · оформление

Промаркируй все окна на активном виде, у которых нет марки.

уровень 1 · листы

Раздели спецификацию «Ведомость перемычек» на части по 30 строк и размести их на листах серии КЖ.

уровень 1 · подсчёт

Посчитай массу арматуры по каждой марке конструкции.

уровень 2 · 3D-элементы

Всем стенам толщиной больше 400 мм на «Этаж 3» поставь «Комментарии» = «Проверить». Сначала покажи список.

уровень 3 · удаление

Удали все пустые помещения на этаже 2. Сначала покажи список.

В хорошем запросе сказано, что найти, где и в каком виде нужен ответ. Если Claude понял неверно, уточните следующим сообщением: переписка продолжается.

Разрешения в Claude Code

Когда Claude впервые хочет вызвать инструмент Revit, Claude Code спрашивает разрешения. В окне видно название инструмента, например revit · find_elements, и его параметры.

Варианты ответа:

Разрешить один разРазрешить всегдаОтклонить
  • Чтение (get_document_info, find_elements, summarize_elements, list_views, export_view_image, wiki_search и т. п.) ничего не меняет в модели. Его можно разрешить всегда.
  • Изменения 3D (set_parameters, place_family_instance, move_elements, delete_elements): разрешайте каждый раз отдельно и читайте, что именно будет сделано.
  • Скрипты (execute_csharp): Revit дополнительно сам покажет код, права скрипта в этой модели и спросит подтверждение. Если не понимаете, что делает код, нажмите «Отмена» и попросите Claude объяснить.

Названия кнопок могут немного отличаться в разных версиях приложения.

Правила безопасной работы

На время бета-теста работайте на копиях или отсоединённых моделях. С локальными копиями рабочих файлов из хранилища — только уровень 1.

  • Claude работает с активным документом. Перед запросом переключитесь на нужную модель.
  • Каждое изменение записывается отдельной операцией с подписью «Claude:» в списке отмены. Отменяется Ctrl+Z в Revit.
  • Пока в Revit открыт диалог или идёт команда (синхронизация, печать), Claude ждёт и через 2 минуты получает отказ. Закройте окно и попросите повторить.
  • Claude может ошибиться в выборе элементов. Для массовых правок сначала просите список и выделение.
  • Изображения видов расходуют лимиты подписки заметно быстрее текста.
Часть 3 · Справка

Уровни доступа

Возможности открываются постепенно. Инструменты выше вашего уровня Claude не видит и вызвать не может.

Ур.Что может Claude
1 Читать модель целиком, считать объёмы и арматуру по всей модели, проверять высоты, расстояния и пересечения. Оформлять: марки и другие аннотации, виды, листы, размещение видов и спецификаций на листах, импорт изображений. Экспортировать в IFC, NWC, DWG, PDF, FBX. 3D-элементы не меняет и ничего не удаляет.
2 Плюс 3D-элементы: заполнять параметры, размещать и перемещать элементы, до 50 штук за запрос.
3 Всё, включая параметры типов, удаление элементов и скрипты без ограничений.

Нестандартные задачи Claude решает небольшими C#-скриптами. Плагин проверяет, что изменил скрипт, и отменяет его целиком, если тот вышел за права вашего уровня в этой модели. Например, на уровне 1 скрипт может расставить марки, а попытку сдвинуть стену плагин отменит.

Где какой уровень действует

Ограничения зависят от модели. Локальная копия файла-хранилища — модель, открытая из хранилища без отсоединения. Свободная модель — отсоединённая от хранилища или обычный файл без совместной работы.

Ур.Корпоративная конфигурацияЛичная конфигурация
1Любые моделиЛюбые модели
2Любые модели. Скрипты меняют 3D-элементы только в свободных моделяхТолько свободные модели
3Любые моделиТолько свободные модели

Вне разрешённых моделей Claude работает на правах уровня 1 и сам скажет об этом.

Как получить уровень

  • Корпоративная конфигурация. Уровень 2 открывается сам, как только выполнится любое из условий: больше 3 дней работы с коннектором подряд, больше 5 дней всего или больше 30 успешных операций. Уровень 3 и другие изменения назначает BIM-менеджер. В пределах доступного уровня можно временно выбрать более низкий (например, для тестов): TNov → Настройки → блок «Коннектор Claude» или окно кнопки Claude. Когда вам откроют новый уровень, выбор сам поднимется до него.
  • Личная конфигурация. Уровень выбираете сами: TNov → Настройки → блок «Коннектор Claude» или окно кнопки Claude.

Текущий уровень, прогресс и уровень в последней модели видны в окне кнопки Claude. После смены уровня начните новый сеанс Claude Code, чтобы появились новые инструменты.

База знаний

Claude сам заглядывает в базу знаний tnov.pm-nova.ru/wiki, когда вопрос касается стандартов Новации, правил оформления или функций TNov, и даёт ссылку на статью. Можно попросить явно: «Посмотри в базе знаний, как у нас оформляют узлы».

Мониторинг подключения

Revit → TNov → Настройки → блок «Коннектор Claude». Статус обновляется каждые 2 секунды.

Claude подключён: запросы были за последние 10 минут.
Запущен, нет запросов: коннектор работает, но Claude давно не обращался или ещё не подключался.
Остановлен: нажмите «Запустить» или кнопку Claude на ленте.

Кнопка Проверить показывает, отвечает ли коннектор и прописан ли он в Claude Code. Там же видно число запросов и последнюю ошибку.

Проверка «прописан ли в Claude Code» находит только подключение командой из терминала. Если вы подключались через файл .mcp.json, строка «не найден» — это нормально.

Если не работает

Claude говорит, что у него нет доступа к Revit
Проверьте по порядку: Revit открыт, кнопка Claude нажата, сеанс Claude Code открыт в папке с .mcp.json и начат после нажатия кнопки. Если Claude Code спрашивал про сервер revit, а вы отклонили, откройте новый сеанс и разрешите.
«Revit не ответил за 120 с»
В Revit открыт диалог, идёт синхронизация или другая команда. Освободите Revit и попросите Claude повторить.
Claude говорит, что такого инструмента нет
Инструмент выше вашего уровня доступа. Уровень видно в окне кнопки Claude.
«Изменения отменены»
Скрипт вышел за права вашего уровня в этой модели, например попытался изменить 3D-элементы на уровне 1 или в локальной копии хранилища. Плагин отменил всё, что сделал скрипт. Claude обычно сам предлагает другой путь; если нужен более высокий уровень, работайте в отсоединённой модели или обратитесь к BIM-менеджеру.
Открыто два Revit
Второй Revit получает адрес с портом 48885, он указан в окне коннектора. Claude работает с тем Revit, чей адрес записан в .mcp.json. Для второго заведите отдельную папку со своим файлом.
«Не удалось открыть порты»
Порты 48884–48893 заняты другими программами. Сообщите BIM-менеджеру.
Скрипт не компилируется в Revit 2022
В Revit 2022 скрипты собираются старым компилятором C# 5. Попросите Claude переписать код без новых конструкций языка.

Что сообщать

По каждой находке отправьте BIM-менеджеру TNov:

  • версию Revit и плагина (окно «Настройки»);
  • ваш запрос к Claude дословно;
  • что ожидали и что получилось, со скриншотом;
  • скриншот блока «Коннектор Claude» после нажатия «Проверить».
TNov · коннектор Revit — Claude (MCP), бета-версия. Коннектор принимает запросы только с вашего компьютера. Данные модели, которые прочитал Claude, уходят в Anthropic в составе вашего сеанса, как и всё, что вы пишете в Claude.
